Gestion du réseau

Importer des données CSV

Ajoutez plusieurs stations ou équipements à partir d'un fichier préparé dans votre tableur. Importez d'abord les stations, puis leurs équipements.

Séparateur : point-virgule. Maximum : 1 Mio et 5 000 lignes de données.

Préparer votre fichier

Télécharger le modèle stations · Télécharger le modèle équipements

Ouvrez un modèle dans votre tableur, remplacez les exemples puis enregistrez en CSV UTF-8 avec des points-virgules. Conservez les en-têtes et leur ordre.

Stations
nom — nom obligatoire, 100 caractères maximum.
Équipements
reference;libelle;type;station;etat — tous les champs sont obligatoires. La station doit déjà exister et être identifiée sans ambiguïté par son nom.

L'import ajoute des données, sans modifier les éléments existants. Les doublons de nom de station ou de référence d'équipement sont refusés, sans distinction de majuscules. Si une ligne est invalide, le fichier entier est annulé.
